# Shaadi Connect

Full-stack wedding planning platform built using React, Spring Boot, Spring Security, JWT, MySQL, Razorpay, and Google Gemini AI.

---

## Features

- JWT Authentication & Authorization
- Vendor Booking System
- Razorpay Payment Integration
- AI Wedding Chatbot
- AI Honeymoon Planner
- Role-Based Admin Dashboard
- RESTful APIs
- Secure Spring Security Configuration

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Spring Boot
- Spring Security
- JPA/Hibernate
- MySQL
- JWT Authentication

### APIs & Services
- Razorpay
- Google Gemini AI
- ElevenLabs

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
